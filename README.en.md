## Download

Pilipili is derived from PiliPlus and retains the original copyright notices under GPL-3.0.

Download a build from [Releases](https://github.com/Yizuka17/PiliPili/releases), or clone the repository and build it locally.

## Disclaimer

Pilipili is a personal project developed for educational purposes, intended only for learning and testing. Please delete it within 24 hours of downloading.
All APIs used were collected from the official website. This project does not provide any cracked content.

Credit to the original project: [guozhigq/pilipala](https://github.com/guozhigq/pilipala).
