# 投票与评分弹幕实验集成

实验分支：`codex/experimental-interactive-danmaku`。

播放器加载当前视频／分 P 的互动弹幕元数据，支持 `#VOTE#` 和 `#GRADE#`。
卡片时间由本体播放器的真实进度驱动。网页端或 App 端推荐的视频均进入同一个播放器路径。
离线视频、直播和画中画不展示这些卡片；关闭弹幕或锁定播放器时隐藏卡片。

卡片继承应用的主题与强调色。
“互动卡片不透明度”可在设置中的播放器设置及视频内的弹幕设置中调节，
两处共用一个持久化值并立即生效，默认 90%，范围 0–100%。0% 时不拦截视频操作。
该值独立于普通弹幕的不透明度。刷新结果按钮仍用于手动读取最新票数与评分。
选择选项／星级后显示“提交”按钮；选择、提交与刷新均不改变视频播放或暂停状态。
卡片使用 Material 3 主题表面与单选状态；窄屏小播放器采用紧凑宽度，
正文可滚动，关闭入口和底部提交操作保持可见，不会因选项增多被裁切。
选择、改选和关闭卡片均不提交。接口确认提交成功后按钮立即消失，即使个人记录读回有延迟，
刷新也不会重新开启同一会话的提交。个人评分在星星右侧以十分制显示。
读取当前主账号的个人参与记录、各项票数、总票数、平均评分和评分人数，
不依赖样例名单。元数据接口已经不返回的卡片无法恢复历史记录。
需要填写自定义文字的投票选项暂不支持提交。

位置解析与官方播放器一致：优先使用非零的 `posX_2/posY_2` 百分比坐标，
否则分别将 `posX/667`、`posY/375` 转成百分比。零或缺失位置回退到中心。
位置代表卡片中心点，卡片尺寸及边缘约束由应用决定。
叠加层将位置映射到实际视频画面，并处理黑边、裁剪、比例、缩放和镜像。
在画面边缘仅作必要的约束，保留关闭与提交按钮。

解析与边缘约束的参考来源：
[官方坐标解析模块](https://s1.hdslb.com/bfs/static/player/main/widgets/npd.505.2d76eed1.js)、
[官方互动卡片布局模块](https://s1.hdslb.com/bfs/static/player/main/widgets/npd.491.8e830665.js)。

网络请求复用本体账号和 Cookie 管理，并绑定加载时的主账号。
切换账号会重新读取卡片；提交前再次读取参与记录。
互动提交明确禁用网络自动重试，避免连接错误时重复产生不可撤回的操作。
切换视频／分 P 会取消旧的元数据请求并释放进度监听。

构建遵循 `.fvmrc`、项目锁定依赖和 Windows SDK／UI 补丁。
入口仍为应用原来的 `lib/main.dart`，独立测试页保留在 `tool/danmaku_probe/`。
可以使用 `tool/build_windows_touch_debug.ps1 -PortableCMake -Mode release -ArtifactSuffix interactive-danmaku`
生成带独立文件名的本地实验包。
